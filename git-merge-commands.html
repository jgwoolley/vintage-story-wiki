Git Merge Command Generator

Merge several GitHub repos, with full history, into subfolders of one repo. Everything runs in your browser.

Paste URLs in any form (https, git@github.com:, ssh://), one per line or in a markdown list. The first is the destination; the rest are merged into it as subfolders named after each repo.
